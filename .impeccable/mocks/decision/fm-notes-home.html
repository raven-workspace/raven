Error Message Lookup

An error tells you how far the attempt got. Read it as a position on this ladder, not as "it failed".

5. Credentials valid? -> STATUS_LOGON_FAILURE / KDC_ERR_PREAUTH_FAILED 6. Account usable? -> LOCKED_OUT / DISABLED / LOGON_TYPE_NOT_GRANTED 7. Enough rights? -> STATUS_ACCESS_DENIED / rpc_s_access_denied
