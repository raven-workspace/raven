# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the actual label strings used in this repo's issue tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | Maintainer needs to evaluate this issue  |
| `needs-info`               | `needs-info`         | Waiting on reporter for more information |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | `ready-for-human`    | Requires human implementation            |
| `wontfix`                  | `wontfix`            | Will not be actioned                     |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table.

Edit the "Label in our tracker" column to match whatever vocabulary you actually use.

These labels live in Linear's RAV team. The category roles map to existing labels: `bug` is `Bug`; `enhancement` is `Feature` or `Improvement`.

## Open questions

`open-question` marks an issue that holds one question an agent found while working on another issue, which that issue didn't settle and the agent left alone (AGENTS.md has the rule). It always arrives with `needs-triage` and is related to the issue that raised it. It's an extra label, not a sixth state role: the issue still carries exactly one state role.

- **Showing what needs attention:** in the `needs-triage` bucket, mark each `open-question` issue as an open question (tag the line `[open question]`).
- **Triaging one** means the owner answers the question. Then either turn it into work (`ready-for-agent` or `ready-for-human`, with a brief that states the decision) or close it as fine as it is, saying so in the closing comment.

## Triage comments

Don't start triage comments or issues with the "*This was generated by AI during triage.*" disclaimer the `triage` skill asks for. Raven carries no AI attribution anywhere, Linear included. Post the comment body alone.
