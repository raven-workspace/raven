3.2

When the terminal has focus

Raven's single-letter keys (L, N, A, P, M, H, J, F, S, ?, 1–7) and Esc are needed by the shell. Rule: while a terminal pane has focus, every key without ⌘ goes to the shell, except ⌃` and ⌃⇧`.

CaseWhat to build
Single letters, digits, ?No change needed: xterm.js types into a hidden textarea, so isTypingTarget() is true and isFreeKey() already refuses them. Add a test that proves it.
EscCode change. useEscapeTo and useEscapeBack in src/lib/keys.ts blur a typing target on Esc, which would throw focus out of the terminal mid-vim. Return early, without blurring, when e.target is inside [data-terminal].
⌘ chordsIn xterm's attachCustomKeyEventHandler, return false for metaKey events (except ⌘C and ⌘V) so ⌘K, ⌘N, ⌘W, ⌘⇧C, ⌘⇧L, ⌘L and ⌘, reach Raven.
⌘C / ⌘VCopy the terminal selection; paste as bracketed paste. ⌃C goes to the shell.
⌃`From the page: show the panel if hidden and focus the last pane. From the terminal: hide it and return focus to what had it before.
? keyThe terminal root carries data-hint-surface, so ? types a question mark instead of opening Shortcuts.
Focus ringArriving by keyboard, the pane gets the 2px accent ring at outline-offset: -2px (inside, so the frame doesn't clip it).
3.3

Motion

Rail bar, tab underlinesGlide 180ms, cubic-bezier(0.16, 1, 0.3, 1) (existing TabMarker). Reduced motion: jump.
Explorer caretsTurn 90° in 150ms (existing DisclosureCaret); children open with Collapse (200 open, 150 close).
Terminal show and hideCollapse values: 200ms open, 150 close. Reduced motion: 120ms fade.
Cursor, sessions, split, resizeNot animated. The cursor never blinks.
3.4

Lifecycle

Who owns a sessionThe Rust backend (a PTY per session), keyed by engagement. Switching pages, hosts or tabs, or hiding the panel, never ends one.
ScrollbackNever written to disk. Only what's captured reaches the vault.
Lock (⌘L, idle)Shells keep running in Rust behind the lock; a lock never kills a caught shell (the same call as the timebox, which also runs through a lock). The webview drops all scrollback with the rest of the query cache. Rust keeps the last 1,000 lines per session in memory only, never on disk, and replays them on unlock.
