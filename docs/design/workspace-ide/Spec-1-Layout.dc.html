1.7

At 1100px, the minimum

Raven's window can't go narrower: tauri.conf.json sets minWidth: 1100. Nothing switches layout at a breakpoint. The numbers below are the editor and terminal widths at 1100 with the Explorer open.

ExplorerNever hides on its own. Explorer on the rail or ⌘B toggles it, as Raven's sidebar does today; closed, the editor takes the 264px back. The rail's accent bar stays on Explorer only while it's open. settled
Chrome barNo change. The search field gets about 320px, enough for its placeholder.
Host pageBoth columns stay (editor about 770px: Facts about 300, Work about 420).
Terminal splitThe divider is draggable: split pane default 320px, main pane at least 480px (about 60 columns). When the window can't fit both, the split pane gives way first. The Split button always works; the main pane wraps if it has to. settled
Status barCells drop in the strip's existing order (useFitStrip): Cleanup, Threads, Metasploit, then the rest. Timebox and LHOST never drop.
