2.5

Capture tab (New log entry)

Replaces the capture sheet (CapturePanel goes). Everything that comes from outside the terminal, a Burp request, a browser screenshot or a note, is pasted here. The form is Raven's CaptureForm with the same fields, keys and save logic, laid out for a tab. Drawn on the Capture tab board.

Opens fromL (not while typing or while a terminal has focus); the Plus on the Explorer's Logs group, "Add log entry · L". One capture tab at a time: opening it again refocuses the tab, draft kept.
Tab"New log entry", last in the tab strip. While it's active, no Explorer row is selected and the Target picker stays on the last host. ⌘W closes it and keeps the draft, as Esc did for the sheet. Esc no longer closes capture.
Pagepadding: 24px, rows max-content minmax(0, 1fr), gap 16. Nothing scrolls at the 360px terminal height.
Top rowGrid max-content minmax(0, 1fr) repeat(3, max-content), gap 8. The kind control (KindChips: Command ⌘1, Screenshot ⌘2, HTTP ⌘3, Note ⌘4, Flag ⌘5; chosen kind in --accent). Then the error line in the flexible track (meta --warn, truncating). Then the toggles that apply ("Returned nothing ⌘." for a command, "Add as credentials ⌘J" when a note holds credentials, "Private ⌘P"), Button size="sm" "Discard", Button variant="primary" size="sm" "Save ↵".
BodyGrid minmax(0, 1.4fr) minmax(16rem, 1fr), gap 24, the host page's columns.
Left: PasteLabel "Paste", then the paste area filling the column's height (resize: none), code type. Focused when the tab opens, so ⌘V lands here and only here. Also takes a dragged image file. Placeholders by kind as today. A screenshot shows its preview here; a flag shows its image thumbnail above the value.
Right: fieldsGap 12, in order: Title (placeholder is the auto title); Caption and "Saved as" for a screenshot; the local.txt / proof.txt choice for a flag; Hosts (chips, then the "+ Host" picker; the Target host is linked to start), then the services or credentials line when there is one; Ran on (picker, 14rem); Observations (Textarea rows=2, "Tentative notes, not proven facts").
Metasploit warningWhen there is one: a meta --warn line under the top row.
Save↵ or Save: the entry is written, the tab closes, focus goes back to the tab that was active before. Discard clears the draft and closes the tab.
